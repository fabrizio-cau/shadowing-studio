# Chrome Web Store submission kit

Everything you paste into the [Developer Dashboard](https://chrome.google.com/webstore/devconsole), field by field.

## Upload

1. `npm run package` builds the extension and writes `release/shadowing-studio-<version>.zip`.
2. Dashboard → **Items → New item** → upload that zip.
3. For updates, raise `version` in `public/manifest.json` (e.g. `1.0.1`), run `npm run package` again
   and upload the new zip on the item's **Package** tab.

**Category**: Education → (sub-category, if offered) Language learning
**Language**: English

**Description**:

```
Practise speaking a language the way interpreters and polyglots do: by shadowing native speakers.

Shadowing Studio turns any YouTube video into a speaking drill. Pick one sentence, loop it, speak along, record yourself and compare your attempt with the original. No more dragging the timeline back and forth or switching between apps.

HOW IT WORKS
1. Open a YouTube video and click the Shadowing Studio icon. The practice panel opens beside the video.
2. Mark the start and end of a sentence with one click each (or type times like 00:01:23).
3. Turn on Loop. The sentence repeats seamlessly, at any playback speed.
4. Record your attempt. Do it again. Every attempt is kept.
5. Play the original sentence and your attempts back to compare them by ear.

TWO PRACTICE MODES
• Shadowing: speak along with the speaker while the sentence loops. Each attempt stops automatically when the sentence ends.
• Listen & repeat: hear the sentence once; the video pauses; then record your imitation.

YOUR PRACTICE LIBRARY
• Segments are organised by language and video.
• Return to any saved sentence later: one click reopens the video at the right spot.
• Rename attempts and add notes on what to improve.
• Export recordings as audio files, neatly organised in folders, to keep or share with a teacher.

PRIVATE BY DESIGN
• Recordings never leave your computer. No account, no cloud, no tracking, no ads.
• Only your microphone is recorded, and only while you press Record. Never the video's sound.
• Works offline except for the video itself.

TIPS
• Use headphones in Shadowing mode so the microphone hears only your voice.
• Slow the video down with YouTube's speed setting while you learn a hard sentence.

Shadowing Studio is an independent project and is not affiliated with or endorsed by YouTube or Google.
```

## Privacy practices tab

**Single purpose description**:

```
Language shadowing practice on YouTube: the user selects a sentence in a YouTube video, loops it, records their own voice with the microphone, and compares and keeps their recordings locally.
```

**Permission justifications**:

| Permission | Justification to paste |
| --- | --- |
| `sidePanel` | The whole practice interface (segment controls, recorder, attempts, library) is displayed in Chrome's side panel next to the YouTube video, so it stays open while the user interacts with the video. |
| `storage` | Stores the user's small preferences (practice mode, default language, auto-stop) in chrome.storage.local. No personal data. |
| `downloads` | When the user clicks Export, saves their recordings as audio files into their Downloads folder (Downloads/Shadowing Studio/<Language>/<Video>/). Never used without a click. |
| `unlimitedStorage` | User recordings are stored locally in IndexedDB. This prevents the browser from evicting a learner's recording library under storage pressure. Nothing is uploaded. |
| Host permission `https://www.youtube.com/*` | The content script reads the current time and duration of the YouTube video element and controls playback (play, pause, seek) to loop the selected sentence. It is limited to youtube.com and does not read page content beyond the video player and title. |

**Are you using remote code?** → **No, I am not using remote code.**
(All JavaScript is bundled in the package; there are no external scripts, no eval, and no remotely
loaded modules.)

**Data usage**: what to tick.

"What user data do you plan to collect from users now or in the future?"

The extension transmits nothing off the device. Whether locally stored data counts as "collected"
depends on the definition shown in the dashboard's help text at the time you submit, so read it there:

- **If it counts only data sent off the device** (the usual reading): tick **nothing**.
- **If it also counts data stored locally**: tick **Website content** only (user-created audio
  recordings and the video titles/timestamps of saved segments). Leave every other category
  (personally identifiable information, health, financial, authentication, personal communications,
  location, web history, user activity) unticked.

Either answer is consistent with `PRIVACY.md`, which describes exactly what is stored locally.

## Distribution tab

- **Regions**: all regions.
- **Pricing**: free.

## Before you press "Submit for review"

- [ ] Run the manual checklist in the README (the real side panel, Chrome's microphone prompt, a real
      microphone with headphones, ads). Automation could not cover these.
- [ ] Load `release/shadowing-studio-<version>.zip` unpacked once (unzip, then *Load unpacked*) to
      check the exact build you upload.
- [ ] The GitHub repository is **public**, so the privacy-policy and support links open for reviewers.
- [ ] The version in the manifest is higher than any version uploaded before.

Review usually takes a few days, sometimes up to a few weeks for a first submission.
